# Система личного кабинета РЖД

Веб-приложение для управления персоналом и рабочими процессами в компании РЖД.

## Технологии

- **Next.js 13** - React фреймворк с App Router
- **TypeScript** - типизированный JavaScript
- **Prisma** - ORM для работы с базой данных
- **SQLite** - база данных
- **Tailwind CSS** - стилизация
- **bcryptjs** - хеширование паролей
- **GO**

## Функциональность

- 🔐 Система аутентификации с хешированием паролей
- 👤 Личный кабинет сотрудника
- 📅 Управление расписанием и сменами
- ✅ Система задач и отчетов
- 👥 Управление командами
- 📚 Обучение и курсы
- 📢 Уведомления
- 🎨 Современный UI/UX

## Установка и запуск

1. **Клонируйте репозиторий:**
```bash
git clone <repository-url>
cd rzd
```

2. **Запуск проекта**
```
docker-compose up --build
```

3. **Открытие в браузере:**
Перейдите по адресу [http://localhost:3000](http://localhost:3000)

## Тестовые данные

После выполнения `npm run db:seed` будет создан тестовый пользователь:
- **Логин:** admin
- **Пароль:** admin123

## Безопасность

- Пароли хешируются с помощью bcrypt
- Используются HTTP-only cookies для сессий
- Middleware защищает приватные маршруты
- Валидация данных на сервере

## Роли ИС
- *worker*: Базовый уровень. Видит только свои данные, расписание и расчетный листок.
- *brigadier*: Имеет доступ к списку своей бригады. Может подтверждать выполнение работ или отмечать явку.
- *dispatcher*: Ключевая роль для РЖД. У него должен быть доступ к управлению сменами, локомотивами или путями.
- *hr*: Работает с личными делами, отпусками и квалификацией всех сотрудников, но не вмешивается в оперативное управление движением.
- *admin*: Техническая роль для управления доступами и просмотра системных логов. (Полный доступ к ИС)
